# 🚗 SmartPark AI — Smart Car Parking System with ML

Real-time parking intelligence powered by **YOLOv8**, **OpenCV**, and **EasyOCR**.

## Features
- 🅿️ **Parking Slot Detection** — Green/Red overlay on each bay
- 🚙 **Vehicle Counting** — Entry & exit tracking with centroid tracker
- 🔍 **Number Plate Recognition** — EasyOCR powered OCR
- 📊 **Live Dashboard** — Real-time stats and occupancy gauge

## Tech Stack
- YOLOv8 (Ultralytics)
- OpenCV
- EasyOCR
- Streamlit
- Python 3.11
